# 📖 Short Stories Showcase

A modern, responsive storytelling web project built with HTML and CSS.  
This project presents short stories in elegant cards with interactive modals using the native HTML `<dialog>` element.

---

## ✨ Features

- 📚 Story cards with preview and excerpts
- 🪟 Full story display using native `<dialog>` modals
- 🎨 Clean design system using CSS variables
- 🌙 Automatic dark mode support (prefers-color-scheme)
- 📱 Fully responsive layout for mobile devices
- 🖨️ Print-friendly mode (prints only the opened story)
- 🎭 Smooth hover animations and micro-interactions
